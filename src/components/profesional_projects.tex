\textbf{LLM Agent for Device Test Analysis:} \textit{OnDosis Digital} \\
Designed and implemented a custom LLM-based agent to support the analytical team in interpreting device test results. \textit{Tech: Go, Docker, LLM} \\

\textbf{Automatic Dispensing Application:} \textit{OnDosis Analytical Testing} \\
Developed a desktop application for executing device dispensing tests with customizable settings in a controlled and repeatable manner. Originally built for the internal test lab, the application became so effective that customers adopted it as well. The tool provides a GUI, configures and triggers tests over BLE, collects more than 100 datapoints per run, and integrates with precision balances for accurate weight measurements. Data is exported in Excel formats preferred by the test teams and supports remote logging and data collection. The impact was significant: internal tests that previously took one week could now be performed in parallel within about one hour, and customer test teams reduced their operator requirements tenfold — from 100 operators down to 10. \\
\textit{Tech: Go, Docker, GUI, BLE} \\

\textbf{LTE Cloud Connector Firmware Application:} \textit{Vinnter AB (in-house project)} \\
Designed and developed a cloud connector application deployed on 300 devices as part of a trial project. On the cloud side, built a custom fleet-provisioning service in AWS using Infrastructure as Code (IaC) to securely and automatically onboard devices, alongside serverless functions for communication, firmware updates, and device management. On the device side, implemented firmware for the nRF9160 SiP using Zephyr RTOS (C), supporting LTE-M connectivity, FOTA upgrades, and certificate rotation. The system posed unique challenges in battery management due to always-on radio requirements while running on battery power. Additionally, I architected the firmware system design for sensor and mechanical integration, with implementation completed by other team members. \\
\textit{Tech: nRF9160 SiP, Zephyr RTOS (C), AWS, Go, IaC, Serverless} \\
